# Howdy Move logo kit (Hat House)

Chosen Nov 10, 2026. Text is converted to outlines, so no font install is needed to use these files.

## Which file to use

| Need | File |
| --- | --- |
| Website header, documents (light background) | `howdymove-logo-horizontal` |
| Dark or denim background | `howdymove-logo-horizontal-reverse` |
| Square spots, flyers, door hangers | `howdymove-logo-stacked` (or `-reverse`) |
| Icon only (stickers, small spaces) | `howdymove-mark` (or `-reverse`) |
| Text only | `howdymove-wordmark` (or `-reverse`) |
| Instagram + Facebook profile pic | `png/howdymove-profile-denim.png` (main) or `png/howdymove-profile-hay.png` |
| Facebook Page cover (1640x624) | `png/howdymove-facebook-cover.png` |
| Website favicon | `png/favicon.ico`, `png/favicon-32.png`, `png/apple-touch-icon.png` |
| App icon / big square icon | `png/howdymove-icon-512.png` |

Profile pics never use a red background. The red hat blends into it.

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Denim | `#1C3D5A` | Main color, "howdy", house |
| Rodeo Red | `#D6452B` | Hat, buttons, "move" |
| Hay | `#F6EAD0` | Light backgrounds, house on dark |
| Big Sky | `#9CC7E8` | Highlights, icons |
| Night Ink | `#14202B` | Body text |
| Coral (on dark only) | `#FF8A6E` | "move" on denim backgrounds |

## Fonts (free, Google Fonts)

- Bricolage Grotesque ExtraBold: logo and headlines
- DM Sans: everything else
